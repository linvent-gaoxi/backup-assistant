# 文件备份助手 C++ 1.0

软件开发综合实验的本机数据备份项目。核心与图形界面均使用 C++17；界面为 Windows 原生控件，不需要 Python、Qt 或 Java。

## 直接运行

双击 `启动备份助手.cmd`，或打开 `bin/BackupAssistant.exe`。

1. “创建备份”：选择源文件夹，选择源文件夹之外的保存位置，使用一个尚不存在的 `.sbackup` 文件名。
2. 筛选条件可留空。默认开启 Huffman 压缩；密码留空表示不加密，填写时至少 8 个字符，并再次确认。
3. “还原与检查”：选择备份文件、一个已经存在的目标文件夹，输入备份密码，然后开始还原。
4. 还原结果位于 `目标文件夹/原目录名`。存在同名文件或目录时停止，换一个还原位置即可。
5. “仅检查备份”会读取并校验全部内容，不创建还原目录；加密文件仍需要密码和临时磁盘空间。

窗口底部显示阶段、已处理文件数、字节数和最终位置。任务在后台运行；运行期间输入被锁定，切换页面仍可使用，关闭窗口会提示等待任务完成。

`examples/示例资料` 包含中文文本、空文件、日志文件和空目录。演示时：

## 功能与筛选规则

| 功能 | 本版实现 |
|---|---|
| 目录备份与还原 | 普通文件、多级目录、空文件、空目录、中文路径 |
| 元数据 | 文件及目录的最后修改时间、只读属性 |
| 自定义打包 | 自行实现 `.sbackup` 单文件格式，含版本标识和清单 |
| 压缩 | 自行实现分块 Huffman；每块最多 1 MiB，收益不足时保存原块 |
| 密码加密 | Windows BCrypt：PBKDF2-HMAC-SHA256、AES-256-GCM |
| 完整性检查 | 整包 SHA-256、每个文件块 CRC32；加密层另外验证认证标签 |
| 图形界面 | 中文界面、文件与文件夹选择、后台任务、状态提示 |
| 命令行 | `backup`、`restore`、`inspect`，与界面共用核心 |

所有填写的筛选条件取“同时满足”。目录本身始终保留，即使目录中的文件均被筛除。

- 文件名：`*.txt`、`报告?.pdf`；`*` 匹配任意长度，`?` 匹配一个字符。
- 相对路径：`文档/*`、`docs/*.txt`；相对源目录，统一使用 `/`，也接受输入 `\`。`*` 可跨越子目录分隔符。
- 扩展名：`txt,pdf,docx`，允许逗号、分号、空白、中文逗号和顿号分隔，可带点；忽略通常的大小写差异。
- 文件大小：非负整数字节，最小值和最大值均包含边界。
- 修改日期：`YYYY-MM-DD`，按运行电脑本地时区解释，包含起止当天。

## 构建与测试

推荐 Windows 10/11 x64、Visual Studio 2022 的“使用 C++ 的桌面开发”组件。

```powershell
.\build.ps1 -Test
```

也可双击 `build.cmd`，会同时构建并运行测试。脚本自动通过 `vswhere` 找到 MSVC，生成静态运行库版本。若没有 Visual Studio，会尝试 PATH 中的 MinGW-w64，建议 GCC 10 或更新版本。

本机实际验证使用 **MSVC 19.44 / Windows x64 / C++17 / /MT**。预先安装的 MinGW 8.1 在 `<filesystem>` 头文件内部编译失败，因此没有使用它生成最终程序；未修改原有编译器。较新 MinGW 分支尚未实际验证。

只运行测试：

```powershell
.\bin\backup_tests.exe
```

结果保存在 `build/test-results.txt`。详细用例、实测性能和人工验收见 `docs/测试记录.md`。

## 命令行用法

```powershell
.\bin\backup_cli.exe backup --source "D:\资料" --output "D:\备份\资料.sbackup" --extensions "txt,pdf" --after "2026-01-01"
.\bin\backup_cli.exe backup --source "D:\资料" --output "D:\备份\加密资料.sbackup" --password-stdin
.\bin\backup_cli.exe inspect --archive "D:\备份\加密资料.sbackup" --password-stdin
.\bin\backup_cli.exe restore --archive "D:\备份\加密资料.sbackup" --destination "D:\还原" --password-stdin
.\bin\backup_cli.exe --help
```

`--password-stdin` 从标准输入读取一行。交互式控制台输入会隐藏回显，程序不接受把密码直接放进命令行参数。重定向时请使用 UTF-8 文本。操作成功退出码为 0，错误为 1，无参数为 2。

## 首版边界

- 本版不包含定时、实时、网络备份，也不读取原 Python 项目的 ZIP 或 `.fbackup` 文件。
- 拒绝链接、重解析点、管道和设备等特殊文件；不保存属主、ACL、访问时间、创建时间、备用数据流、硬链接关系和稀疏属性。硬链接按独立普通文件保存。
- 备份文件不能放在源目录里；不会覆盖已有备份或合并已有还原目录。
- 不使用卷影快照。备份期间应保持源资料不变；正在被写入或无法读取的文件会使任务失败，不会静默跳过。
- 加密处理使用临时明文文件，需在可信本机磁盘上操作。失败时自动清理；进程被强制终止或断电后可能残留 `.sbackup-*` 临时项，系统启动不会自动删除它们。普通删除不等于安全擦除。
- 每块数据内存有界；文件清单留在内存，条目上限为 100 万。长路径能力受操作系统和运行库影响，本版没有保证超长路径支持。
- 完整报告、答辩 PPT 与演示视频尚未制作；测试与说明为后续报告提供真实依据，不虚构人员分工或开发历史。

课程要求 C/C++ 等语言作为后台；本版符合该语言选择方向。打包和 Huffman 编解码自行实现，加密与 SHA-256 使用系统 BCrypt，界面使用系统控件；是否折算扩展分及具体分数由教师认定。
