## 性能实测

本机临时目录内单次运行，未清理文件系统缓存；数据用于复现和说明，不作为跨设备性能保证。

| 数据集 | 原始大小 | 归档大小 | 备份耗时 | 还原耗时 |
|---|---:|---:|---:|---:|
| 单文件、16 MiB 相同字节 | 16,777,216 B | 16,713 B | 87 ms | 564 ms |
| 1000 个文件，每个 128 B 相同字节 | 128,000 B | 172,977 B | 302 ms | 620 ms |

大文件用例压缩后约为原始大小的 0.10%。小文件中频率表不足以节省空间，自动选择原始块，清单开销使归档略大于原文件总和。两组均已逐文件验证还原内容。

## 桌面人工验收

通过 Windows 桌面控件实际操作，不依赖 Python 运行程序：

1. 启动 `bin/BackupAssistant.exe`，检查中文标签和控件显示。
2. 在界面选择示例源目录与新归档位置，扩展名填 `txt`，Huffman 开启，输入并确认演示密码。
3. 点击创建备份，观察处理中按钮禁用、任务状态与完成反馈。
4. 切换还原页面，填写该归档、示例目标目录及密码，成功生成原目录名子目录。
5. 用 SHA-256 对比两个 txt 文件：完全一致；空目录保留；日志文件未还原。
6. 界面调整后再次启动检查：字体按系统 DPI 缩放，中文标签及底部状态区可见；空路径提交弹出“请选择源文件夹和备份保存位置”。
7. CLI 对相同加密归档执行 `inspect --password-stdin`，返回成功、2 个文件、3 个目录和 110 原始字节。
8. 检查可执行文件依赖，仅包含 Windows 系统 DLL，不依赖 Python、Qt 或额外 VC 运行库 DLL。
