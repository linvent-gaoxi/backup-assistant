# 腾讯云桌面版

双击项目根目录的 `BackupAssistant.exe`。在「设置 → 服务器地址」填入 `ssh://TencentCloud` 或 `https://127.0.0.1:19444`，点击「连接并保存」。下次启动会使用最后成功连接的地址。腾讯云连接使用现有 SSH 别名和密钥，选择腾讯云时不依赖 WSL。

连接成功后，在登录页注册并登录。账号由 1～40 个字母、数字、下划线或连字符组成，密码至少 8 个字符。账号在两台服务器上分别注册，每个账号拥有独立的备份空间、回收站和自动任务。退出会撤销会话并暂停该账号的自动任务，下次登录后继续。旧演示账号 `demo` 的归档仍保留在旧账号空间，需要管理员按需迁移。

选择本地地址时，客户端自动启动 WSL 的本机 HTTPS 存储服务。两种连接都由 Windows 读取源目录、打包、还原和执行自动任务。两台服务器的备份空间、回收站和任务各自保存。切换地址时，已经运行的 Windows 后台组件仍可执行各自的任务。旧 WSL 控制台的归档目录未迁移到新版仓库。

腾讯云上的 `backup-assistant-cloud.service` 管理 HTTPS 服务。Windows 客户端自动开启 SSH 隧道并验证服务证书。云端端口只监听服务器本机。上传后的归档保存在云端账号的备份空间，本机临时归档在任务完成后清理。下载在 Windows 指定目录内解包。

定时和实时任务由 Windows 客户端的后台组件运行，关闭桌面窗口后后台仍可执行。Windows 关机或后台组件停止期间无法读取本地源文件。备份空间和回收站由腾讯云保存，云端会自动清理超过七天的回收站项目。

旧 WSL 归档及早期 HTTPS 分块仓库中的验收版本没有自动迁入新的云端备份空间。未加密归档会尝试与同目录的同组历史归档对比 SHA-256 分块，只发送缺失块和清单。服务器验证完整归档后发布，下载仍可还原完整版本。加密归档和没有可复用块的归档使用整包上传。右键选择「归档内容与版本」可查看历史归档与未加密归档的文件清单。

Ubuntu 原生命令行使用 linux/build.sh 构建。它可备份和还原 Linux 普通权限、属主、属组、修改时间、相对软链接、硬链接关系和 FIFO。恢复不同属主或属组需有相应系统权限。软链接目标限于不含上级目录跳转的相对路径。新版 Windows 客户端继续处理 Windows 归档，Linux 格式归档请用 Ubuntu 命令行还原。
